One original dad joke, delivered by a small Python script — entered in make.fun's [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty. A judge model reads two jokes at a time and picks the one that works better as a dad joke: the pun, the groan, the straight-faced delivery.

> My guitar's been feeling strung out lately. I told it to fret less.

## Run it

```sh
python3 main.py
```

That writes the joke to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output` if unset).
